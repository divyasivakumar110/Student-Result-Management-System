🚀 A smart and simple web-based application to manage student results efficiently using HTML, CSS, and JavaScript.

---

## 📌 About the Project

The **Student Result Management System** is a web application designed to help users manage student academic records easily.

It allows users to:
- ➕ Add student name and marks
- 🧮 Automatically calculate total, average, and grade
- 📊 Display results in a structured table
- 🗑️ Delete student records instantly

This project is **beginner-friendly**, responsive, and built using core frontend technologies.

## 🚀 How It Works

1. Enter student name and marks  
2. Click **Add Result** button  
3. System calculates total, average, and grade automatically  
4. Data is displayed in a table  
5. You can delete records anytime
